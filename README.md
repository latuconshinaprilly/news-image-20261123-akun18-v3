# THE DAY'S HERALD

Monday 23 November 2026 — the whole day on one page: the Kyiv rescue,
Hormuz, COP31, the House vote, Wellington's record, and the rest of the
day's wires, each with its place, its certainty tag, and its source.

## Run it

    python3 main.py

That places `entry.png` into the folder named by `MAKEFUN_OUTPUT_DIR`
(default: `out`). The page itself is drawn by `compose.py`; `main.py`
only carries the finished page across.
